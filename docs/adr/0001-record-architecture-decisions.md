# ADR 0001: Record architecture decisions

- Status: accepted
- Date: 2026-11-19

## Context

Uniondeb monitors people's communications. Decisions about data, access and automation must be
explainable later, to reviewers, auditors and the people affected.

## Decision

Record significant decisions as ADRs in `docs/adr/`, numbered. Superseded ADRs stay in place,
marked superseded.

## Consequences

Each ADR cites the evidence it rests on (a script, a results file, a document), and a test checks
that the cited files exist.
